# 爱心弹窗 (Heart Popup)双击运行 `爱心弹窗.exe` 后:1. **依次弹出** 多个**普通窗口样式**的小窗口(有标题栏), 客户区底色为纯粉色, 沿爱心曲线**等弦长(等距)**分布, 每 **0.05 秒** 弹出一个。2. 全部弹出后, 它们拼成一个完整的爱心形状。3. **停留 5 秒**。4. 然后按弹出顺序 (从第一个到最后一个) **依次关闭**, 每 **0.02 秒** 关闭一个。5. 全部关闭后程序自动退出。窗口使用 `WS_OVERLAPPEDWINDOW` 普通样式 (标题栏 / 系统菜单 / 最小化最大化按钮), 仅客户区底色为粉色。相邻窗口沿爱心曲线**等弦长(等欧氏距离)**分布, 间距相等; `kSpacingRatio < 1` 时相邻窗口互相**重叠**, 从而在同一个爱心上放置**更多窗口**。窗口数量按屏幕大小自适应, 实测 1920×1080 约 62 个、2560×1440 约 86 个、1366×768 约 42 个。## 可调参数 (main.cpp 顶部)| 参数 | 默认 | 含义 ||------|------|------|| `kClientW` / `kClientH` | 126 / 82 | 小窗口客户区尺寸 (像素, 不含标题栏, 放大以显示祝福语) || `kSpacingRatio` | 0.5 | 中心间距 = 窗口尺寸×该比例 (**<1 即重叠**, 越小窗口越多) || `kGap` | 4 | 相邻窗口额外间距 (像素) || `kFitMargin` | 0.99 | 爱心+窗口外框占屏幕比例 (半径尽量大且保证不溢出) || `kPopDelayMs` | 50 | 弹出间隔 (0.05 秒) || `kHoldMs` | 5000 | 全部弹出后停留时间 || `kCloseDelayMs` | 20 | 关闭间隔 (0.02 秒) || `kPink` | RGB(255,105,180) | 纯粉色 (可改成其他纯色) || `kTitles[]` | 祝福语数组 | 各窗口标题 (循环使用) |## 构建### 方式 A: CMake (推荐)```batcd D:\爱心\heart-popupcmake -B build -G "Visual Studio 17 2022"cmake --build build --config Release```生成 `build\Release\爱心弹窗.exe`。### 方式 B: MSVC 命令行在 "x64 Native Tools Command Prompt for VS" 中:```batcd D:\爱心\heart-popupbuild.bat```或直接:```batcl /EHsc /O2 /std:c++17 main.cpp /link user32.lib gdi32.lib /SUBSYSTEM:WINDOWS /ENTRY:wWinMainCRTStartup /OUT:"爱心弹窗.exe"```### 方式 C: MinGW g++```batg++ -O2 main.cpp -o "爱心弹窗.exe" -luser32 -lgdi32 -mwindows```## 实现说明- 使用 Win32 API (`CreateWindowExW` + `WS_OVERLAPPEDWINDOW`) 创建**普通窗口样式**的小窗口 (有标题栏), 仅客户区底色填充纯粉色; 每个窗口标题取自祝福/提醒语列表。- 爱心曲线采用经典参数方程:  `x = 16 sin³t`, `y = 13cos t − 5cos 2t − 2cos 3t − cos 4t`。- 对曲线做精细采样后, 按爱心实际**包围盒居中**到屏幕, 并按屏幕比例缩小半径, 保证完整显示不溢出 (含底部尖角)。- 沿折线做**闭环等弦长(等欧氏距离)**放置: 相邻窗口中心直线距离恒定, 视觉上真正等距。- 该爱心曲线在上下两处存在**尖点**, 直接行走会在起点留下一段不均匀的接缝; 程序**扫描弦长 D** 并同时尝试"保留/丢弃末点"两种闭环方式, 在满足间距偏差阈值的前提下选最小 D(即窗口最多)的方案, 实测间距偏差 < 0.4%。- 窗口数量由弦长与重叠比例自动决定。- 用一个隐藏宿主窗口 + `SetTimer`(10ms) 驱动状态机 (弹出 → 停留 → 关闭), 能分辨 20ms 的关闭间隔。- 窗口使用 `WS_EX_TOPMOST` 置顶, 保证爱心完整可见。
